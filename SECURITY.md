# Security Policy

## Reporting a Vulnerability

Please don't report a vulnerability in a public issue or pull request: report it privately, with [Report a vulnerability](https://github.com/carlosplanchon/nanosaas/security/advisories/new), in the repository's Security tab. Only the maintainers see it.

Say what someone could do with it, and how: the steps, the requests, or a test that shows it.

## Supported Versions

Fixes go into the latest release. NanoSaaS is a template that you deploy and change, so to get a fix, bring your installation up to the release that has it, as the README's Development Notes say.
