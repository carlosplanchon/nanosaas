For the queued tasks to survive a restart of Redis, and a crash, turn on its
append-only file: Redis writes every change to it within a second.

On a Redis that already has data, turn it on while Redis runs, so it writes its
data to the file first. Restarting it with the setting, before that, starts it
empty:

redis-cli config set appendonly yes

Then add this to /etc/redis/redis.conf, so it stays on after a restart:

appendonly yes
appendfsync everysec
